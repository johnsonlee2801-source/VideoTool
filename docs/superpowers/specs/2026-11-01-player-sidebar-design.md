# 播放器右侧统一侧栏设计

日期：2026-11-01

状态：2026-11-01 用户确认具体设计并授权按实施步骤完成、运行 TDD 与 CC Suite 验证。
基线：`0f073a2b501cf8531afc1534b18e74e84d4c006b`

## 用户目标与已确定的选择

将现有独立视频库页面融入播放器右侧，使用户查看分类、最近播放时间、观看进度及选片时无需切换窗口。用户已选择右侧三个标签切换：**视频库／最近播放／星标**。

沿用现有 AppKit、libmpv、Theme、索引和数据存储。整理仍然只建立索引，不移动、改名或重写用户视频文件。已有分类、文件夹、缩略图、观看记录与星标保持可用。

## Approaches / 方案比较

1. **统一侧栏，三个标签切换（用户已选）**：一次展示一种内容，留出足够的浏览空间；换标签不需要换窗口。视频库和星标不能同时展开，这是为保持画面及侧栏清晰所做的取舍。
2. **视频库与星标上下同时显示**：可以同时查看，但小窗口中两边都需要滚动，搜索和文件夹管理也更拥挤，因此未选。
3. 继续使用独立窗口无法解决用户反复切换窗口的问题，不作为本次实现方案。

以下具体交互和尺寸最初由实现者建议，已随本文获得用户确认。

## 布局与视觉

- 主窗口为左侧播放画面、右侧统一侧栏，底部继续共用播放控制条。侧栏参与布局，不遮住视频画面；视频保持原比例。
- 侧栏顶部是「视频库／最近播放／星标」标签和收起按钮。选中标签使用现有粉色强调色，分隔线、卡片、文字沿用 Theme 的深色层次与对比度。
- 默认宽度约 380 pt，可拖动分隔线调整；建议范围 280–560 pt，并至少给播放区保留 240 pt。宽度随窗口可用空间限制，不强行放大窗口。
- 视频库使用纵向紧凑卡片：左侧约 112×63 pt 的 16:9 缩略图，右侧为文件名、类别标签、时长/清晰度及观看状态；当前播放项有清晰的选中提示。列表复用/按需创建可见项，避免一次加载所有缩略图。
- 播放画面双击仍切换原生全屏。进入或退出全屏保持侧栏的展开状态；用户可以在全屏中手动收起侧栏。
- 整个侧栏区域均不触发播放器的双击全屏，包括标签、列表空白、搜索框和分隔线。

## 打开、关闭和状态

- 新用户首次默认收起侧栏，打开视频本身不强制展开；下次启动恢复侧栏是否展开、最后标签和用户调整的宽度。
- 播放控制条增加明确的「视频库」入口；`⌘L` 与原「视频库」菜单都展开侧栏并切换到「视频库」，重复使用时保持展开，不创建第二个窗口。
- 现有星标按钮与 `⇧⌘B`：侧栏未打开或当前是其他标签时展开并进入「星标」；已经处于「星标」时收起侧栏，保留原按钮的开关习惯。
- 侧栏内部切换标签不暂停播放，也不清空当前搜索、分类或滚动位置。搜索条件按标签分别保存于本次会话，不额外保存到磁盘。
- 打开侧栏不自动扫描整个磁盘；只沿用用户已经加入的视频库文件夹。保留手动添加文件夹与重新扫描入口。
- 用户主动开始的索引任务在收起侧栏或切换标签后继续运行；关闭播放器或退出应用时取消任务并释放回调。

## 三个标签

### 视频库

顶部提供搜索框、整理方式选择、文件夹筛选，以及紧凑的添加/重新扫描入口。保留现有全部、剧集、文件夹、文件日期、时长、清晰度、重复文件和内容标签分类，以及原有文件夹与剧集修正操作。

单击选中卡片，双击在左侧播放器打开该视频。播放切换后侧栏保持打开，并保留当前分类、查询和滚动位置。添加目录仍需用户通过系统目录选择器选定。

### 最近播放

- 按最近播放时间倒序展示，每个文件路径一条最近记录；显示「今天 14:30」等时间、观看进度以及「继续观看／已看完」。这是最近状态列表，不是每次打开事件的完整日志。
- 基于现有 WatchHistoryStore，保留历史记录；成功加载的视频立即记录最近播放时间，随后播放进度更新继续使用现有机制。
- 未加入视频库但已经播放过的本地视频也能出现。能匹配索引时复用缩略图和标签；没有索引时用文件名及已有时长/进度展示，不为了显示记录自动索引目录。
- 文件已不可用时仍保留记录，用户尝试打开时显示明确提示，不静默移除历史，也不跳转到其他文件。
- 只在打开标签、记录变化及索引结果变化时刷新相关内容；节流并保留滚动、选择和输入状态，不靠频繁整库扫描刷新时间。
- 旧记录缺少最近播放信息时不伪造日期。现有「按日期」仍指文件元数据日期，不与最近播放混淆。

### 星标

复用当前星标列表：双击跳转到星标前 2 秒、备注编辑、删除及快捷键语义保持一致。数据仍关联当前视频；视频库/历史标签不替代星标数据。

## 键鼠、错误和数据边界

- 搜索、备注编辑、列表选择和列表导航优先由侧栏处理，不被播放器的空格/方向键抢走。原有带修饰键的菜单快捷键正常使用。
- 按住视频加速时按键仍先取消手势；切换文件、关闭窗口等路径继续清理手势和待执行单击，避免延迟暂停。
- 复用同一视频库模型，避免不同标签互相覆盖单个 onChange/onProgress 回调。索引、历史、星标变化通过明确的刷新入口更新可见视图。
- 数据库暂时不可用时在侧栏内显示可重试错误，播放器仍能使用；重新展开时允许重试，不永久缓存一次失败。
- 面板偏好从 AppData.defaults 获取，新测试数据、数据库、缩略图和历史记录仍使用隔离的测试目录，不能触碰真实用户数据。
- 不引入新依赖、账号、网络服务或付费调用，不扩展 AI 分类能力，也不批量重新识别已有视频。

## 实现边界

将视频库的可复用内容从 NSWindowController 生命周期中解耦，由播放器统一侧栏承载。AppDelegate 不再持有或创建独立视频库窗口，原入口均路由到当前播放器。

保留现有分类/索引与存储规则，改造窄侧栏布局及刷新机制。旧窗口测试和快照转为嵌入内容及单窗口交互测试，不以保留无入口的独立窗口作为迁移完成条件。新增文件通过 project.yml 和 scripts/regen.sh 管理，不手改 xcodeproj。

本次不涉及 Apple TV 投屏、片段端点拖动或 GitHub 演示素材选择。版本号或新 DMG 发布不包含在布局确认中；完成实现后更新本机应用，并按项目规则同步源码及中文更新说明。

## 验收与 TDD

先编写并实际运行失败用例，再实现；用户选定的三个标签、单窗口和已有交互都落实为行为断言。至少覆盖：

1. `⌘L`、菜单及视频库按钮打开同一播放器侧栏，没有额外视频库 NSWindow。
2. 三标签切换、收起/重开、宽度边界和隔离偏好恢复；切换不改变播放/暂停状态。
3. 视频库分类、搜索、文件夹筛选与索引进度；双击打开路径及侧栏状态保留。
4. 未索引视频的最近播放、时间倒序、成功加载即出现、进度/已看完以及失效文件处理。
5. 星标原有跳转/编辑/删除行为；搜索和备注输入不触发播放快捷键。
6. 实际命中侧栏标签、搜索、列表及空白处不触发全屏；播放区域双击、单击、长按、右键仍通过回归。
7. 数据库暂时失败后的重试、收起时索引继续、关闭播放器后取消与回调释放。
8. UI 快照检查空库、已有视频、最近播放、星标及窄窗口；中英日文本完整。

定向测试通过后运行项目配置的完整 TDD Guardian 推送门禁及密钥扫描；安装版检查单窗口使用路径、搜索输入、播放切换和全屏往返。源代码测试、安装版实测及 GitHub/安装包发布分别说明。
