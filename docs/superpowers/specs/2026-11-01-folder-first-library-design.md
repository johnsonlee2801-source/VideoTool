# 文件夹优先的视频库与手动下一集

日期：2026-11-01

状态：用户于 2026-11-01 确认按本文实施，并要求完成后运行 TDD 与 CCSuit 检测。
基线：`1284b8c619e36a9967fe6a50ae0d8f79136f757a`

## 用户已决定的方向

- 用户通常已按文件夹整理视频，视频库应清楚展示文件夹及其中的视频，方便按第 1、2、3 集顺序观看。
- 文件夹承担主要浏览，分类作为额外筛选；缩略图要小，界面紧凑、便捷。
- 到下一集时停下来，由用户决定是否继续；子文件夹同样由用户主动进入。
- 延续播放器右侧「视频库／最近播放／星标」，不另开浏览窗口，不移动或重命名原文件。

下面的具体布局、尺寸和交互细节由实现者建议，已随本文获用户确认。

## Approaches / 方案取舍

1. **推荐：可收起的文件夹导航＋同一区域的紧凑列表。** 路径与返回入口持续可见，文件夹导航按需展开，进入目录后显示其子文件夹和视频。适合现有 280–560 pt 侧栏，不新增常驻横向面板。
2. 常驻目录树与视频列表左右并排：目录层次直观，但窄侧栏会严重压缩文件名空间，因此不作为默认布局。
3. 仅保留根目录下拉框、按文件夹分组：改动较小，但无法清楚进入下层目录，也不利于按一个目录连续看，因此不足以满足本次目标。

## 浏览与布局

- 保留现有侧栏宽度、拖动和收起行为，不扩大播放器窗口。
- 「视频库」默认按文件夹浏览；首次显示已加入的视频库根目录，以后恢复上次有效位置。打开视频不强制展开侧栏，也不突然把用户正在浏览的目录切走；提供定位当前视频所在文件夹的入口。
- 路径栏显示当前位置、返回上一级及可展开的文件夹导航；长路径收缩显示，完整路径可查看，并保留在 Finder 中显示的操作。
- 进入目录后先显示子文件夹，再显示该目录直接包含的视频。子目录不自动展开，不把整棵目录树的内容混进同一列表。
- 已索引目录的层次及数量从现有索引推导，只展示含有已索引视频的目录；数量明确区分本层视频和子目录，避免同名目录或同名根目录混淆。
- 视频行建议约 62 pt 高，缩略图约 80×45 pt；主要展示文件名、时长、观看进度和当前播放标识。文件夹使用更矮的图标行，不占一张视频卡片的高度。
- 搜索默认作用于当前文件夹，界面标明范围；分类、标签、观看状态等放在可收起的筛选入口。原有日期、时长、清晰度、重复文件、剧集修正等整理能力保留在次级入口。
- 切换标签、收起侧栏、播放其他视频后，保留目录、筛选、选择和滚动位置。目录位置可通过 AppData 隔离偏好恢复；搜索和滚动按当前会话保留。
- 对未加入视频库但正在播放的本地视频，可主动查看同目录视频：只在后台读取这一层，不递归扫描、不自动加入索引、不批量生成缩略图；占位图保持可用，用户可自行添加该文件夹到视频库。

## 顺序与手动继续

- 同一目录的视频复用自然文件名排序，保证 `1、2、10` 的顺序；同名文件以完整路径稳定兜底。原文件不改名，也不依靠自动内容分类重新排列集数。
- 上一集／下一集按当前播放文件所在目录的完整视频顺序决定，不跨目录、不循环回第一集。搜索及分类筛选只影响找片，不暗中改变下一集目标。
- 提供紧凑的上一集／下一集操作，并能看到下一项文件名；用户点击才加载，加载沿用现有播放进度恢复规则。
- 自然播放结束后停在当前视频，显示本集结束和下一集入口，不弹出阻挡画面的确认窗口，也不倒计时自动播放。
- **已有跳片尾行为一并调整：**目前 `skipOutroIfReached` 会自动寻找并打开下一集。本次保留跳片尾、完成观看和进度清理语义，但跳到本集结尾后暂停，下一集由用户点击进入。自动跳片头的现有行为保留。
- 目录末尾没有下一集时将按钮置灰；磁盘断开、文件删除或访问失败时给出明确提示，不静默跳到别的目录或视频。
- 读取目录和排序在后台进行；切换文件、目录或关闭播放器后，旧请求不得覆盖新的列表或下一集目标。

## 实现边界与复核

- 复用 LibraryController、LibraryStore、观看历史、现有侧栏及 Theme；目录层次、排序与相邻视频选择拆成可测试的纯逻辑，AppKit 只负责展示和事件接线。
- 不改变索引的文件所有权规则，不增加新数据库格式、网络服务、付费模型或全盘扫描。新文件通过 project.yml 和 scripts/regen.sh 管理。
- 当前会话核对了 LibraryBrowserViewController、LibraryGrouping、LibraryController、PlayerSidebarView、SeriesNavigator 和跳片尾路径；未调用其他代理。
- 当前根目录筛选只有平面入口，目录分组本身已有自然排序，可复用；需要新增的是层级导航、紧凑呈现和明确的同目录手动继续。
- 不涉及 Apple TV、片段端点、GitHub 演示素材或新 DMG 发布。

## TDD 与验收

1. 目录层级、同名根目录、父子路径边界、当前层与子目录数量；不显示不相关目录的视频。
2. 自然排序与上下集边界；不同搜索／分类条件不改变手动下一集目标。
3. 正常结束、跳片尾后均不自动加载下一集；点击下一集只加载一次并保留既有进度规则。
4. 已播放／未播放、当前视频定位、历史刷新、目录选择和滚动保持。
5. 未索引文件同目录浏览、慢目录请求过期、文件失效、不可用磁盘及非递归读取。
6. 280、380、560 pt 布局快照及中英日文本；侧栏不误触发全屏，键盘、画面单击和长按保持回归。
7. 用户决定先写测试并实际运行失败，再实现、运行通过并做当前会话 Codex Suite 审查。旧跳片尾自动连播测试改为覆盖新手动行为，不能删去验证。
8. 完整 TDD Guardian 门禁、秘密扫描、Release 构建通过后，按已有授权更新并重启本机播放器、保留旧版备份，推送 GitHub 并写日期中文更新说明。安装二进制核对与实际鼠标验收分别报告。
