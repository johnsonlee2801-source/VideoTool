# 哔哩哔哩公开点播接入

用户已批准：复用“打开网络视频”入口，支持完整链接、分享短链接、公开普通视频、右侧紧凑分 P 手动选择；验证原有倍速、全屏、星标和续播。无需登录，不读取 Cookie，不处理会员、番剧、直播和弹幕。
