# 已批准的播放器体验优化

顺序：网络播放体验 → 继续观看入口 → 片段两端微调 → 字幕搜索与逐句回看。

1. 网络体验：拖入／粘贴受支持链接，显示解析、缓冲、实际画质；错误仅输出安全类别，提供对应操作；手动重试重新解析签名地址，从中断位置继续。输入框与侧栏编辑保留粘贴；不自动安装组件、读取凭据或扩站。
2. 继续观看：右侧紧凑入口显示本地与单独的网络记录；可继续或从头开始；网络记录只保存规范网页身份、标题与进度，不进入本地索引；保持 EOF 手动下一集。
3. 片段微调：基于 C 标记与循环预览增加两端拖动和精确时间调整，不改变本地导出边界。
4. 字幕回看：右侧按需搜索已有字幕并跳转、重听上一句；使用本地已有字幕／AI 结果，不将网络播放加入 AI 或导出流水线。网站字幕接入在确认兼容、安全与真实验收后单独落地。

每一步：失败测试 → 实现 → 相关回归与 UI 快照 → CC Suite 当前会话审查 → 完整 TDD 门禁 → 中文更新说明 → GitHub 提交推送。第一步已安装；后续三项完成后统一 Release／本机验证，减少重复重启。已有未跟踪 .codex-suite/ 保留。覆盖率／变异不以通道通过替代。
