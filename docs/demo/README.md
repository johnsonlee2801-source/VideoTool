# Demo subtitles

`tos-open.zh.srt`: the opening of [Tears of Steel](https://mango.blender.org)
(CC BY 3.0, © Blender Foundation), subtitled by VideoTool itself on 2026-10-20:
Apple's on-device speech recognition for the English lines, Apple Translation for
the Chinese ones, nothing edited by hand. Used for the README pictures
(`tools/make_docs_screens.sh`).
