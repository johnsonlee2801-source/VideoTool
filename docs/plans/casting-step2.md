# 投屏第 2 步：把画面投到 Apple TV / 电视（方案，待实机）

状态：2026-10-19 写好方案，**等用户在场、有可测设备时再做**。
理由：mpv 渲染的画面不能直接走 AirPlay；竞品评论里投屏是"付费后最失望"的功能（投不上、只有声音、字幕丢、每几分钟跳回），不能未经实机就上线。

## 做法

1. **只对系统能直接投的文件开放**：MP4 / MOV / M4V，视频 H.264 或 HEVC，音频 AAC / AC-3 / E-AC-3。
   判断：`AVURLAsset.isPlayable` + 轨道编码检查。其他格式（MKV、AVI、WebM…）菜单里置灰，并提示"这个格式暂时不能投屏"。
2. **交给系统播放器投**：建一个 `AVPlayer`，`allowsExternalPlayback = true`。控制栏放一个 `AVRoutePickerView`（系统的 AirPlay 按钮），由用户选设备。
3. **接力**：
   - 选中设备、`isExternalPlaybackActive` 变为真时：记下 mpv 的位置、速度和暂停状态，暂停 mpv；AVPlayer 从同一位置、同一速度开始播放。
   - 结束投屏时反向接回 mpv。
   - 投屏期间，控制栏的播放、拖动、倍速、星标都操作 AVPlayer。
4. **字幕**：外挂字幕和 AI 字幕需要先转成 WebVTT，再作为 `AVMediaSelectionGroup` 提供。MP4 内嵌的 tx3g 字幕可以直接用。第一版可以先只保证内嵌字幕。
5. **续播与历史**：投屏期间每 5 秒照常写入续播位置和观看记录。

## 实机验收清单（用户在场）

- [ ] 在 Apple TV 或支持 AirPlay 的电视上，投 1080p H.264 MP4：开始、暂停、拖动、2× 倍速、结束投屏后接回 Mac，位置连续。
- [ ] 投 4K HEVC：画面正常、不卡、不跳回。
- [ ] 连续播放 15 分钟不断开，不跳回开头（竞品通病）。
- [ ] 带内嵌字幕的 MP4，电视上能看到字幕。
- [ ] MKV 文件：投屏入口置灰，并有说明。
