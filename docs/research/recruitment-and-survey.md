# 招募帖与线上问卷

用法：招募帖由你本人发到下面的渠道；问卷题目复制进腾讯问卷（或问卷星），生成链接后替换帖子里的 [问卷链接]。
问卷只收集必要信息：不问姓名、手机号、学校；联系方式（微信号或邮箱）只在对方愿意访谈时选填。

## 发在哪里（按优先级）

| 渠道 | 用哪版 | 怎么发 |
|---|---|---|
| 朋友圈、学校/社团群 | A | 最快拿到前几位受访者；配一张播放器截图 |
| 小红书 | A 或 C | 发图文笔记：首图用 README 的播放截图，话题加 #Mac软件 #效率工具 #倍速 #网课；评论区回复问卷链接（正文放外链容易限流） |
| 即刻 | B 或 C | 发到「Mac 软件推荐」「独立开发」类圈子 |
| V2EX | C | 发在「分享创造」节点，附 GitHub 链接；技术圈愿意试用、也会认真提 issue |
| 豆瓣小组 | A | 网课、追剧、动漫相关小组；先看组规是否允许招募 |
| Reddit r/macapps（英文） | C 英文版 | 晚一点再发：等中文反馈改过一轮之后 |

建议节奏：先发 A 到朋友圈和群里约 3–5 个访谈；同时在 V2EX / 即刻发 C 收试用反馈；一周后看问卷回收情况再发小红书。

## 一、招募帖

### 版本 A：小红书 / 朋友圈（口语）

> 感兴趣的话评论区扣 1，或者先填这个 2 分钟的小问卷 👉 [问卷链接]

## 二、线上问卷（约 2 分钟，12 题）

**开头说明**：这份问卷用来改进一款 Mac 视频播放器，匿名填写，约 2 分钟。最后一题可以选择留下联系方式参加 30 分钟访谈，送小礼物。

1. 你的年龄段：18 岁以下 / 18–22 / 23–26 / 27–30 / 30 岁以上
2. 你现在是：学生 / 上班族 / 其他
3. 你主要用什么电脑看视频？（单选）Mac / Windows / 都用
4. 一周用电脑看视频大概几次？少于 1 次 / 1–2 次 / 3–6 次 / 几乎每天
5. 主要看哪些内容？（多选）网课 / 讲座 / 剧集 / 综艺 / 电影 / 动漫 / 外语视频 / 游戏或录屏 / 下载的短视频 / 其他
6. 平时用什么看？（多选）浏览器或视频网站 / IINA / VLC / PotPlayer / QuickTime / Infuse / 其他
7. 你会开倍速吗？
   - 从不 / 偶尔 / 经常 / 几乎一直开
   - （如开）最常用多少倍：1.25 / 1.5 / 2 / 2.5 / 3 倍以上
8. 下面哪些情况让你烦过？（多选，最多 5 个）
   - 格式打不开
   - 字幕乱码、不同步、找不到
   - 外语视频没有中文字幕
   - 倍速调起来麻烦
   - 想回看某个片段找不到位置
   - 下载的视频太多太乱，找不到
   - 不知道上次看到哪了
   - 画质发灰、发暗（HDR）
   - 卡顿、发热、费电
   - 投不到电视上
   - 声音忽大忽小、对白听不清
   - 其他：____
9. 上题里**最烦**的是哪一个？为什么？（简答）
10. 如果有一个功能能**免费、在本机**给任何视频自动生成中文字幕，你会用吗？
    - 一定会 / 可能会 / 不太需要
11. 下面哪些功能你**愿意付费**？（多选）
    - 批量导出片段、GIF（带字幕、更高画质）
    - 任意格式投屏到电视
    - 画质增强（补帧到 60 帧、动漫超分）
    - 多台电脑同步进度和收藏
    - 播放 NAS / 网盘里的视频
    - 都不愿意
12. 愿意花 30 分钟参加线上或线下访谈吗（送小礼物）？
    愿意的话，请留下微信号或邮箱：______（只用于约时间，访谈结束后删除）

## 三、回收后怎么用

- 第 8、9 题：按选择人数排序，前 3 名对照我们的功能顺序。
- 第 7 题：确认常用倍速，看现在的预设（0.75–3.0）是否合适。
- 第 10、11 题：用来验证"AI 字幕免费"和会员候选清单。
- 第 12 题：留了联系方式的人，就是访谈对象。优先挑第 9 题写得具体的人。
