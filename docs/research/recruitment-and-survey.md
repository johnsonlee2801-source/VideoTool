# 招募帖与线上问卷

用法：招募帖复制到小红书、朋友圈、学校群、即刻或 V2EX，由你本人发布；问卷题目复制进腾讯问卷或问卷星。
问卷**不要收集**手机号、微信号以外的个人信息；联系方式只在对方愿意参加访谈时才填。

---

## 一、招募帖

### 版本 A：小红书 / 朋友圈（口语）

> 🎬 **找 6 位爱用电脑看视频的朋友，聊 30 分钟，送一杯奶茶～**
>
> 我在做一个 Mac 上的视频播放器（按住画面就能加速、进度条上能打星标、自动整理本地视频），想看看大家平时看网课、追剧、看动漫时都卡在哪儿。
>
> ✅ 18–30 岁
> ✅ 一周至少 3 次用电脑看视频（网课、剧、动漫、下载的视频都算）
> ✅ Mac 或 Windows 都可以，**习惯用 PotPlayer 的尤其欢迎**
>
> 📍 线下（XX 附近）或腾讯会议线上都行，全程不拍脸，录音只用于整理，整理完就删。
> 🥤 做完送奶茶 / 小红包。
>
> 感兴趣的话评论区扣 1，或者先填这个 2 分钟的小问卷 👉 [问卷链接]

### 版本 B：V2EX / 即刻（偏技术圈）

> **[求助] 找几位用电脑看视频比较多的朋友做 30 分钟用户访谈（Mac 播放器）**
>
> 个人开发的 macOS 播放器，基于 libmpv：按住画面加速、左右拖动调速（0.5–6×），进度条星标，本地视频库自动归类，后面会做**本机离线的 AI 字幕和翻译（免费）**。
>
> 想找 18–30 岁、每周多次用电脑看视频的人，看你实际怎么用、在哪里卡住。不推销、不收集隐私，线上即可，会送一点小心意。
>
> 不方便访谈的话，填个 2 分钟问卷也非常感谢：[问卷链接]

## 二、线上问卷（约 2 分钟，12 题）

**开头说明**：这份问卷用来改进一款 Mac 视频播放器，匿名填写，约 2 分钟。最后一题可以选择留下联系方式参加 30 分钟访谈，送小礼物。

1. 你的年龄段：18 岁以下 / 18–22 / 23–26 / 27–30 / 30 岁以上
2. 你现在是：学生 / 上班族 / 其他
3. 你主要用什么电脑看视频？（单选）Mac / Windows / 都用
4. 一周用电脑看视频大概几次？少于 1 次 / 1–2 次 / 3–6 次 / 几乎每天
5. 主要看哪些内容？（多选）网课 / 讲座 / 剧集 / 综艺 / 电影 / 动漫 / 外语视频 / 游戏或录屏 / 下载的短视频 / 其他
6. 平时用什么看？（多选）浏览器或视频网站 / IINA / VLC / PotPlayer / QuickTime / Infuse / 其他
7. 你会开倍速吗？
   - 从不 / 偶尔 / 经常 / 几乎一直开
   - （如开）最常用多少倍：1.25 / 1.5 / 2 / 2.5 / 3 倍以上
8. 下面哪些情况让你烦过？（多选，最多 5 个）
   - 格式打不开
   - 字幕乱码、不同步、找不到
   - 外语视频没有中文字幕
   - 倍速调起来麻烦
   - 想回看某个片段找不到位置
   - 下载的视频太多太乱，找不到
   - 不知道上次看到哪了
   - 画质发灰、发暗（HDR）
   - 卡顿、发热、费电
   - 投不到电视上
   - 声音忽大忽小、对白听不清
   - 其他：____
9. 上题里**最烦**的是哪一个？为什么？（简答）
10. 如果有一个功能能**免费、在本机**给任何视频自动生成中文字幕，你会用吗？
    - 一定会 / 可能会 / 不太需要
11. 下面哪些功能你**愿意付费**？（多选）
    - 从视频里剪出片段或 GIF
    - 任意格式投屏到电视
    - 画质增强（补帧到 60 帧、动漫超分）
    - 多台电脑同步进度和收藏
    - 播放 NAS / 网盘里的视频
    - 都不愿意
12. 愿意花 30 分钟参加线上或线下访谈吗（送小礼物）？
    愿意的话，请留下微信号或邮箱：______（只用于约时间，访谈结束后删除）

## 三、回收后怎么用

- 第 8、9 题：按选择人数排序，前 3 名对照我们的功能顺序。
- 第 7 题：确认常用倍速，看现在的预设（0.75–3.0）是否合适。
- 第 10、11 题：用来验证"AI 字幕免费"和会员候选清单。
- 第 12 题：留了联系方式的人，就是访谈对象。优先挑第 9 题写得具体的人。
