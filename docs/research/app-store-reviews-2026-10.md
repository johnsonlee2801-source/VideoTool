# 桌面视频播放器 App Store 用户评论调研（2026-10）

> 案头研究，只读公开数据。日期：2026-10-19。目的：弄清楚真实用户对 Mac 视频播放器在抱怨什么、想要什么，给 VideoTool 的功能取舍做参考。

## 1. 方法

**App ID**：通过 `itunes.apple.com/search?entity=macSoftware` 在 cn、us 两个区查到。

**分类方法**：
1. 先给每个主题写中英文关键词规则，自动打标签。一条评论可以同时属于多个主题。
2. 然后人工通读：速度、AI 字幕、HDR、音频、投屏、性能、字幕这几个主题的 1–3 星评论全部读完；格式、价格、界面、媒体库、崩溃这几个主题抽样读，大约读了每个主题的 1/3 到 1/2。读的过程中删掉误判的关键词，比如"卡"在中文里含义太多，"TV"不一定是投屏。
3. 另外随机读了 5 星评论的样本，并对几项和 VideoTool 直接相关的需求（书签、长按变速、记忆设置、跳过片头、进度条缩略图等）做了全量关键词检索后逐条阅读。

## 3. 前 8 个主题的代表性原话

英文原文已翻译成中文，全部去掉了昵称和个人信息。

### 3.1 价格 / 订阅 / 付费墙
- "连自定义倍速都收费……吃相太难看。"（Fig Player，1 星）
- "视频暂停就弹 VIP 提示弹窗，看学习视频时暂停记笔记就弹，很烦。"（OmniPlayer，1 星）
- "我真的不喜欢用订阅制来**播放视频**这个想法，有点侮辱人。"（Infuse，1 星，译）
- "长途国际航班上才发现，已付费的功能要联网才能启用。"（Infuse，1 星，译）

### 3.2 格式 / 解码支持
- "我想做一件非常非常简单的事：播放一个 AVI 文件。"（Elmedia Video Player，1 星，译）
- "打开 20G 以上的原盘视频，黑屏无声音……设备是丐版 M1 MBA。"（OmniPlayer，3 星）
- "ISO 的基础播放都做不到……但凡你老实写出来，而不是在简介里写支持。"（VidHub，1 星）

### 3.3 界面 / 操作 / 键鼠手势
- "切换视频时不保存配置，每次切换后窗口大小、播放倍速都变回默认值。"（OmniPlayer，3 星）
- "这么基础的空格暂停都不让用。"（Fig Player，1 星）
- "触控板双指滑动不能快进快退是硬伤。"（SenPlayer，3 星）
- "画中画不会浮在全屏窗口上面，等于没用。"（Elmedia Video Player，1 星，译）

### 3.4 网络 / NAS / 网盘
- "挂载 115 几天都卡住，扫描不出影片……iCloud 也完全不同步。"（Infuse，1 星，Mac）
- "播放百度网盘和 115 的视频要好几分钟才开始，用 VidHub 一秒内就能播。"（Infuse，3 星）
- "相比浏览器播放同样的 WebDAV，电脑发烫。"（VidHub，1 星，Mac）

### 3.5 媒体库 / 续播 / 剧集
- "希望增加播放历史列表……周更剧集有时候真的会忘了自己看到哪集。"（Infuse，3 星，Mac）
- "看了一半退出去，从播放记录继续观看直接闪退，然后记录也不见了。"（VidHub，1 星）
- "经常播放途中自动结束并切换到下一集，不知道怎么触发的。"（VidHub，3 星，Mac）
- "不能自定义分类，动漫和电视剧混在一起，找一个想看的要翻好久。"（VidHub，1 星）

### 3.6 稳定性 / 崩溃 / 更新回退
- "更新 macOS 26.5 后，播放所有视频格式都提示错误、闪退。"（Infuse，3 星，Mac）
- "快捷键全毁了……原本常用的功能全部打乱。"（Movist，1 星，Mac）
- "播放流畅，但会让我的 Mac 卡死并崩溃。"（MKPlayer，3 星，Mac，译）

### 3.7 字幕（含 AI 字幕）
- "98 元买断，本以为能享受所有功能，结果突然弹窗要求翻译字幕按次收费。"（Fig Player，1 星）
- "开了翻译，45 分钟的剧显示要 6 个小时才能翻译好，电脑风扇狂转、很烫。"（Fig Player，1 星，Mac）
- "一句台词的字幕直接重复成接下来所有台词的字幕……每翻译一次都要付费。"（Fig Player，3 星）
- "字幕没有延迟保存功能，同一部电影第二次打开又要重新设置。"（SenPlayer，2 星）

### 3.8 性能 / 发热 / 音画不同步
- "Mac 版发热极其严重，一打开软件温度就飙到 99 度。"（VidHub，1 星，Mac）
- "选 1.5 倍速时发热严重，视频明显卡顿。"（Fig Player，3 星，iMac）
- "Mac mini M4 拖进度条或用方向键快进时，画面要卡几秒才切过去。"（Infuse，3 星，Mac）
- "同一部在线 HDR 视频，用你的播放器能耗直接顶满，键盘发烫。"（SenPlayer，2 星，Mac）

### 补充：和 VideoTool 直接相关的几个小主题
- **倍速 / 长按**："能否加一个按住屏幕快速播放的功能：按住时 2 倍速，手指往右滑加速、往左滑减速，最低到 0.5。"（Infuse，5 星，功能请求）这和 VideoTool 的长按拖动变速**几乎一模一样**。"长按倍速时会突然停一下，松开时也停一下，希望能连贯。"（VidHub，3 星）"短按右方向键居然变两倍速，按理说两倍速应该是长按。"（OmniPlayer，3 星）"自定义倍速播放下一个视频时又恢复默认。"（Fig Player，2 星）"超过 4 倍就没声音了。"（Fig Player，1 星）
- **书签**："喜欢书签这个功能，好像 IINA 还没有。"（Fig Player，5 星）"能否像 PotPlayer 那样用快捷键跳到下一个书签？"（Fig Player，5 星）"视频文件挪位置以后书签就消失了，挪回原位置又恢复。"（OmniPlayer，5 星，提问）"上传网盘再下载回来，书签就没了。"（Fig Player，5 星）
- **投屏**："每看五六分钟就跳回到五六分钟前重新播放。"（OmniPlayer，3 星）"投屏无字幕，切勿购买会员。"（Fig Player，1 星）
- **音频**："打开时音量默认最大，经常吓人一跳……应该记住上次的音量。"（OmniPlayer，3 星）"有的电影音量忽大忽小……希望新增自动均衡音量。"（Fig Player，5 星，请求）

### 5 星评论在夸什么
- **"什么都能放"**：格式是 5 星里最常出现的主题（497 条），大量是"终于能在 Mac 上放 AVI、WMV、MKV"这类一次性需求。
- **简洁、无广告、不打扰**：MKPlayer 好评占 82%，好评几乎都是"干净、简单、易用"。
- **买断而不是订阅**："只花一点钱就什么都能放，不用订阅。"（SenPlayer）
- **开发者响应快**、更新勤快（SenPlayer、VidHub）。
- **画质和杜比支持做得对**是 Infuse 被反复夸的地方，其他 App 的 HDR 差评也常拿它当标杆。
- **书签、截图、时间戳复制**这类"拉片 / 学习"工具被少数人重度依赖，而且称赞时会点名说 IINA 和 Mac 上其他播放器都没有。

## 4. 对 VideoTool 的启示

### 4.1 现有或已计划的功能能回应的抱怨
| VideoTool 功能 | 对应的用户抱怨 / 期望 | 判断 |
|---|---|---|
| 长按加速 + 拖动调速（0.5–6x） | 有用户主动描述了几乎相同的交互；"短按变倍速很怪""长按时卡一下" | **方向被直接验证**。要守住两点：按下和松开都不能有卡顿或静音；拖动时要清楚显示当前倍速 |
| 固定倍速档位 | 倍速收费、倍速不能锁定、切下一个视频就回到默认 | 倍速**免费**，并且记住"上次用的倍速"或允许按视频 / 按系列记忆，都是差异点 |
| 星标书签（时间线上） | 书签是好评主题、Mac 上少见；痛点是"文件挪位置或跨设备书签丢失""不能用快捷键跳到下一个书签""想导出" | 强需求信号。**书签要绑定文件内容指纹而不是路径**；做"跳到上 / 下一个书签"快捷键；以后可以考虑导出 |
| 自动整理本地视频库 | 刮削不准、动漫和剧集混在一起、不能自定义分类、扫描极慢且占 CPU | 本地库是机会，但"自动"必须允许手动纠正并且纠正后要记住；扫描要做增量、低优先级 |
| 计划：继续观看 | 播放记录丢失、"不知道看到哪集"、想要单独的历史列表 | 高价值。进度必须可靠持久化（崩溃后也不能丢） |
| 计划：系列分组 | 季、集识别错，自动跳下一集出 bug | 自动连播要可控、可以关掉，而且绝不能在没播完时跳走 |
| 计划：免费的本地 AI 字幕 + 翻译 | Fig Player 的反面教材：买断后再按次收费、45 分钟的视频要转 6 小时且发烫、关掉 App 任务就丢、识别重复或幻觉 | **"免费 + 本地"正好打在最大痛点上**。工程上要保证：任务可以断点续传、能后台排队、能限制功耗、生成的字幕文件落盘在视频旁边、明确告诉用户预计耗时 |
| 计划：HDR / 画质测试 | 点不亮、偏暗、偏色、全屏后变黑；用户会拿 Infuse 和 QuickTime 做对照 | 用户会做 A/B 对比。测试集要包含窗口和全屏切换、Dolby Vision P5/P8 的色彩 |
| 计划：投屏 | 投屏是"付费后最失望"的功能：投不上、只有声音、字幕丢、每几分钟跳回去 | 风险高、口碑容易翻车。要么做到稳定，要么晚点做；**不要把它当付费墙** |
| libmpv 内核 | 格式和解码是第一大低星主题；多个用户说"换 IINA 或 VLC 就好了" | mpv 的覆盖面是天然优势。宣传时要诚实，比如蓝光加密、ISO 菜单等说清楚做不做 |

### 4.2 还没计划、但评论里反复出现的缺口
1. **"记住我的设置"**：音量（默认不能是 100%）、倍速、窗口大小和位置、字幕延迟、选中的音轨和字幕轨，按文件或全局记忆。成本低，抱怨多。
2. **不打扰原则**：不弹付费窗、不在暂停时弹窗、不催评分、不偷改默认播放器、不要剪贴板权限。这类行为直接导致 1 星。
3. **能耗和发热预算**：Mac 用户对风扇和续航非常敏感，而且会拿别的 App 对比。建议把"播 1 小时 4K / 1080p 的能耗"列为发布门槛，倍速和 AI 字幕场景也要测。
4. **拖动进度条、方向键快进要即时**：多个 App 被骂"快进要卡 2–3 秒""拖动后没声音"。和长按变速一起，属于"手感"层面的硬指标。
5. **进度条缩略图预览**（34 条）和**跳过片头片尾**（30 条），这两个是看剧的常见诉求。
6. **字幕基本功**：同目录同名字幕自动加载、编码自动识别（GBK、Big5）、ASS 字体和特效、字幕大小和位置实时调整、双字幕不重叠、延迟实时预览。AI 字幕之前要先把这些做好。
7. **音量均衡 / 对白增强**：电影里爆炸声太大、对白太小，这类请求反复出现，对给孩子看的场景尤其有用。
8. **离线可用**：买断功能不能依赖联网校验（有人在飞机上被锁）。
9. **键鼠和触控板细节**：空格暂停、单键快捷键、双击全屏、可以关掉触控板手势（和切换桌面的三指手势冲突）、PiP 置顶、播完退出全屏时恢复原来的窗口状态。
10. **清除观看记录 / 隐私**：量很小（4 条），但和"家庭共用一台 Mac"的场景相关。
11. **年轻观众这个定位在评论里几乎没有声音**：明确提到孩子或家庭的只有约 6 条；"学习、网课、看教程"场景反而有 58 条（倍速看课、暂停记笔记、书签拉片）。这说明，要么"年轻观众"是 App Store 评论里看不到的人群（家长不写评论），要么真正的高频场景是"学习型观看"。**建议在用户访谈里专门核实这一点**。

## 5. 局限

- **iOS 和 Mac 混在一起**：Infuse、VidHub、SenPlayer 的 ID 多端共用，评论以 iPhone、Apple TV 为主；全部样本里只有约 700 条（≈10%）明确提到 Mac。网络 / 网盘、投屏、HDR 这几个主题受影响最大。
- **RSS 的上限**：每个 App 每个区最多 500 条最新评论，热门 App 只覆盖到最近 1–2 年；Movist、Elmedia 能回溯到 2011–2015 年，部分抱怨（比如 Flash/SWF、老版 macOS）已经过时。
- **只有两个商店区**：cn 区用户的关注点（网盘、刮削、中文字幕编码）和 us 区（AVI、AirPlay、订阅反感）差别很大，其他地区没覆盖。
- **评论本身有偏差**：不满的人更愿意写，好评里可能有刷评和"弹窗逼出来的评分"；很多评论只有一句话，没有上下文。
- **分类是关键词加人工抽读**：表里数字是关键词命中数，会有误判（一条评论可以属于多个主题，中文"卡"和英文"sync"之类的词有歧义）；人工只全读了小主题，大主题是抽样读的。数字只能看量级和排序，不要当成精确比例。
- **没有覆盖 IINA、VLC、QuickTime**：它们不在 Mac App Store 上，或者评论入口不同，但评论里经常被拿来当参照（"换 IINA 就好了"）。要了解开源播放器用户的诉求，需要另外看 GitHub issues、论坛。
- **没有看到目标用户**："年轻观众和他们的家长"在 App Store 评论里几乎没有出现，这份调研不能替代对目标用户的访谈。
