## VideoTool を作った理由

講義、ドラマ、アニメ、画面収録、ダウンロードした動画。多くの人が 1.5 倍や 2 倍で見て、退屈なところは飛ばしています。早く見終わりたい、でも大事な場面は逃したくない。VideoTool はそんな見方のために作りました。

- **🖱 長押しで速く、ドラッグで微調整。** 画面を長押しするとすぐ 2 倍速になります（いつも倍速で見ているなら、その速度よりさらに一段速く）。押したまま右へドラッグすると最大 6 倍、左へドラッグすると遅くなり、指を離せば元の速度に戻ります。
- **★ シークバーにスター。** いい場面で **B** を押すと、サムネイル付きのスターがシークバーに付きます。メモも残せます。クリックすれば 2 秒前から再生されるので、前後の流れもわかります。2 つのスターの間を MP4、GIF、静止画として書き出せます。
- **🌐 AI字幕と翻訳が無料。** 英語、日本語、中国語、韓国語などのビデオに、見ながら字幕を作成します。いま見ている位置から始まり、数秒で表示されます。訳文は原文の上に、細い半透明の帯の上に表示されます。すべて **Mac の中だけで** 処理するので、アップロードも料金もありません。.srt ファイルとして保存することもできます。
- **📚 自分で整理されるライブラリ。** ビデオを開くと、そのフォルダをライブラリに追加するか確認します。エピソードはシリーズごとに話数順に並び、「続きから見る」がいつも手元にあります。重複ファイルを見つけ、映っている内容にタグも付けます。ファイルを移動したり名前を変えたりすることはありません。
- **🎞 どんな形式でも再生。** mpv と FFmpeg を採用しているので、MKV、HEVC 10-bit、HDR10、AV1、VP9、WMV、FLV、古い AVI、複数の音声トラックや字幕トラックも扱えます。ハードウェアデコードにより、4K HDR でも CPU 1 コアの約 5 分の 1 しか使いません。
- **⏭ 待ち時間を減らす。** オープニングの終わりとエンディングの始まりを一度指定すれば、そのシリーズの全エピソードで自動的にスキップし、次のエピソードへ進みます。シークバーにポインタを置くとプレビューが出ます。ナイトモードは声を聞きやすくし、爆発音の重低音を抑えます。
- **🧠 ビデオごとに記憶。** 再生位置、選んだ音声トラックと字幕、字幕のタイミング調整は、次に開いたときにも残っています。
- **🔒 プライバシー重視。** アカウント不要で、トラッキングも分析もしません。ライブラリ、スター、字幕は `~/Library/Application Support/VideoTool` に保存されます。

## ほかのプレーヤーとの違い

Mac にはすでに優れたプレーヤーがあります。VideoTool が加えるもの、そしてほかのプレーヤーのほうが優れている点をまとめました。

| | VideoTool | IINA | VLC | Infuse |
|---|---|---|---|---|
| 価格とソース | 無料、オープンソース（MPL-2.0） | 無料、オープンソース | 無料、オープンソース | 無料、Pro はサブスクリプション |
| 画面の長押しで速く | 2 倍、ドラッグで 0.5〜6 倍 | — | — | 2 倍 |
| サムネイルとメモ付きのスター | ✓ | — | ブックマーク（サムネイルなし） | — |
| Mac 上で字幕を作成して翻訳 | ✓（macOS 26） | ダウンロードのみ | VLC 4 で予告 | ダウンロードのみ |
| クリップ、GIF、静止画の書き出し | ✓ | スクリーンショット | 変換/保存で可能 | — |
| フォルダからシリーズ別に整理 | ✓ | — | — | ✓（オンラインのアートワーク付き） |
| オープニングとエンディングのスキップ | ✓（一度指定） | — | — | ✓（オンラインのデータベース） |
| MKV、HEVC、AV1、HDR の再生 | ✓ | ✓ | ✓ | ✓ |

Windows、Linux、スマートフォンでも使うなら **VLC**、NAS や Plex、Jellyfin からのストリーミングや Apple TV には **Infuse**、プラグインやオンライン動画を備えた成熟した mpv プレーヤーなら **IINA** がおすすめです。VideoTool は、手元のビデオを、いい場面を逃さずに早く見るためのプレーヤーです。

<sub>2026 年 10 月時点の各アプリの公開情報にもとづきます。誤りがあれば Issue でお知らせください。</sub>

## 速度は思いのまま

| したいこと | 操作 |
|---|---|
| 一時的に速く | 画面を長押し（2 倍、またはいつもの速度 + 0.5 倍） |
| 長押し中にさらに速く / 遅く | 右へドラッグ（最大 6 倍）/ 左へドラッグ（最小 0.5 倍） |
| 速度を固定 | シークバー横の速度表示をクリック：0.75× – 3× |
| 細かく調整 | `[` / `]`（±0.1×）、`⌫` で 1.0× に戻す |

選んだ速度は記憶されます。講義をいつも 1.5 倍で見ているなら、次に開いたときも 1.5 倍です。6 倍まで上げても、声ははっきり聞こえ、ミュートされることはありません。

## キーボード

| キー | 動作 | キー | 動作 |
|---|---|---|---|
| スペース | 再生 / 一時停止 | B | スターを付ける（すぐもう一度押すと取り消し） |
| ← / → | 5 秒戻る / 進む（⇧：30 秒） | ⌥← / ⌥→ | 前 / 次のスター |
| ↑ / ↓ | 音量 | ⇧⌘B | スター一覧 |
| ⌘T | AI字幕 | S / A | 字幕 / 音声トラックを切り替え |
| ⌘L | ライブラリ | F | フルスクリーン |
| M | ミュート | ⌘O | ファイルを開く |
| Z / X | 字幕を 0.1 秒早く / 遅く | ⌘E | クリップを書き出す |

## 動作環境

- macOS 14 Sonoma 以降。Apple シリコンで動作を確認しています。
- AI字幕には **macOS 26** 以降が必要です。言語ごとの音声モデルと翻訳データは、システムが一度だけ無料でダウンロードします。

## インストール

1. [Releases](https://github.com/johnsonlee2801-source/VideoTool/releases/latest) から **VideoTool-x.y.z.dmg** をダウンロードし（Apple シリコンと Intel の両方に対応）、開いて VideoTool を「アプリケーション」にドラッグします。
2. 初めて開くとき、macOS は開発元を確認できないと表示します。VideoTool はまだ Apple の公証を受けていないためです。**完了** をクリックし、**システム設定 › プライバシーとセキュリティ** を開いて下へスクロールし、VideoTool の横の **このまま開く** をクリックして確認します。これは最初の一度だけです。

ソースからビルドすることもできます（Xcode と [XcodeGen](https://github.com/yonaskolb/XcodeGen) が必要です）。

```sh
brew install xcodegen
git clone https://github.com/johnsonlee2801-source/VideoTool.git
cd VideoTool
scripts/regen.sh          # Xcode プロジェクトを生成
scripts/install.sh        # Release ビルドを /Applications にインストール
```

すべてのビデオを VideoTool で開くには、**ファイル › デフォルトのビデオプレーヤーに設定…** を選んでください。macOS が形式ごとに確認を求めます。

## 表示言語

インターフェイスは **English、简体中文、日本語** に対応し、Mac の言語設定に合わせて切り替わります。

## 品質

VideoTool はテストファーストで開発しています。約 450 の自動テストがあり、本物の再生エンジンや、Mac 上での本物の音声認識もテストしています。同梱したビデオ形式も一つずつ確認しています。プッシュのたびに個人情報が含まれていないかを自動で確認し、行カバレッジは 90% を超えています。詳しくは [CONTRIBUTING.md](CONTRIBUTING.md) をご覧ください。
